# Quellenhinweise

Dieses Repository ist öffentlich. Deshalb werden rohe Exporte, umfangreiche Provenienzarchive und nicht notwendige Rohdaten **nicht automatisch in GitHub gespiegelt**.

## Kanonische Evidenz

Aktuelle externe Belege werden strukturiert in `data/claims.json` mit folgenden Angaben geführt:

- Quelle/URL
- Evidenzklasse A–D
- Claim-Typ
- Stand (`as_of_date`)
- letzte Verifikation
- Confidence

Das zentrale Quellenregister liegt in `data/source_registry.json`.

## Externe Projektarchive

Ältere Deep-Research-Berichte, Businessplan-Sammlungen, Gemini-/Demo-Exporte und weitere Projektquellen können außerhalb des öffentlichen Repositories archiviert bleiben. Ihre bloße Existenz gilt nicht als Marktevidenz.

**Regel:** Nur unabhängig verifizierte Claims der Klassen A–C dürfen das Core-Scoring beeinflussen. Klasse D bleibt für Core-Scoring gesperrt.
