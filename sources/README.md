# Quellenhinweise

`verified/` bedeutet: als primäre Forschungsbasis des Projekts vorgesehen. Einzelne Claims innerhalb eines Dokuments können trotzdem unterschiedliche Evidenzqualität haben.

`unverified/` enthält ältere, teilweise modellgenerierte, demonstrative oder noch nicht sauber quellengeprüfte Materialien. Diese Dateien dienen nur Provenienz, Ideenarchiv und Vergleich. **Sie dürfen nicht direkt für Core-Scoring oder Marktbehauptungen verwendet werden.**
